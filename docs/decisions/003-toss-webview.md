# 003: 토스 전용 WebView 앱과 광고 흐름

결정일: 2026-10-20 (한국 시간)

## 플랫폼 구성

공식 create-ait-app 0.2.9의 TDS 구성을 확인해 `apps/toss`를 별도 Vite·React 18 앱으로 구현한다. SDK 3.8.1과 TDS 2.5.1을 고정하며 웹/PWA React 19는 유지한다. TypeScript는 각 앱의 로컬 React 타입을 paths로 지정해 pnpm의 간접 타입 호이스팅으로 두 React 버전이 섞이지 않게 한다. 런타임 React를 공통 패키지에 추가하거나 타입 검사를 끄지 않는다.

공통 contracts/data만 재사용하며 UI·라우팅·OpenLayers 지도·SDK 조립은 토스 앱이 소유한다. 별도 공유 UI 패키지는 만들지 않는다. 프로필은 SDK Storage, 위치 권한은 Device.getLocation, 시스템 뒤로가기는 graniteEvent로 처리한다. 토스의 네이티브 상단 영역을 복제하지 않고 콘텐츠 헤더를 웹 내부에 구성한다. 중복 지도 메뉴는 제거하고 현재 위치 버튼은 지도 위에 둔다. 실제 상단 영역·키보드·권한·뒤로가기는 별도 기기 검증 대상이다.

## 화면과 광고

사용자와 합의한 메인 지도·지점 상세·운동기구 상세 하단 배너와 지도 선택 시 전면 광고를 구현한다. 접근성용 시설 목록에서도 같은 선택 흐름을 사용한다. 전면 광고는 준비된 경우 첫 선택에서 노출하며 실제 표시 후 최소 2분 간격을 적용한다. 광고 시각은 SDK Storage로 복원하고 광고 미준비·실패 시 상세로 바로 이동한다. 광고 길이를 앱에서 강제로 제한하지 않는다.

배너는 SDK 규격을 유지하고 실패·미충전·미지원 시 영역을 접는다. 본문·배너·Safe Area는 flex 레이아웃에서 별도 영역으로 계산한다. 광고를 콘텐츠/버튼 위에 겹치거나 임의 축소하지 않는다.

## 검증 경계

테스트 광고 모드와 운영 모드를 분리하고 기본은 off로 둔다. SDK·DB 대체 Chrome 검사는 로컬 회귀 확인용이며 실제 광고·위치·V-World 도메인 허용이나 출시 심사를 대신하지 않는다. 사용자 승인으로 `.ait` 테스트 업로드를 완료했다. 공개 검토·출시는 별도 승인 단계다. 연결값은 사용자가 토스 앱 환경에 설정하며 업로드 자격 증명은 로컬 CLI 프로필에만 보관한다.

실행 방법·검증 결과의 범위·실기기 확인·공식 출처는 [토스 문서](../toss.md)를 따른다.
