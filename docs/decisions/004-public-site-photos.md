# 004: 공개 지점 대표 사진의 제한된 조회

2026-10-21. 앱 코드 구현·사용자의 운영 DB 적용 완료. 비로그인 운영 API 및 사용자의 토스 사진 표시 확인 완료.

조사 PWA → 관리자 → 사용자 서비스는 같은 Supabase를 공유한다. 관리자에서 중복 지점 사진 경로를 비웠으므로 사용자 서비스도 연결된 조사 사진을 읽어야 한다. 사용자 앱에 조사 전체 SELECT 권한을 주지 않기 위해 고정 SELECT의 SECURITY DEFINER RPC를 사용한다. 공개 지점 ID에 해당하는 대표 경로 한 값만 반환하고 조사 사진이 없을 때 기존 지점 경로를 사용한다.

앱별 화면과 세션은 유지하고 공통 `packages/data`에서 RPC와 Storage 서명을 처리한다. 사진 RPC·정책은 사용자 승인 및 SQL Editor 실행으로 적용했다. 버킷의 비공개 전환은 관리자·조사 앱 호환성 검증 후 진행할 후속 작업이다. 구체적인 적용 순서·제한·검증·복구는 [사진 조회 문서](../site-photos.md)를 따른다. 전체 workspace 통합은 이 결정의 범위에 포함하지 않는다.
